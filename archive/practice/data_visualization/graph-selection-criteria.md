# 데이터 시각화에서 그래프를 고르는 기준 정리

이 문서는 데이터 시각화에서 **어떻게 그리는가**보다 **왜 이 그래프를 선택하는가**에 초점을 둔 개인 학습 노트이다.

---

## 목표
- 그래프를 그리고 끝나는 것이 아니라
- **그래프 선택 이유를 말로 설명할 수 있는 상태**가 되는 것

---

## 1. DataFrame — 시각화를 위해 이것만 알면 된다
DataFrame은 엑셀 표와 같은 구조이며, 핵심은 다음 두 가지다.

- 행(row)
- 열(column)

**시각화는 열(column)을 그리는 작업이다.**  
그래프는 항상 특정 열을 기준으로 만들어진다.

---

## 2. 그래프를 선택하는 사고 순서
그래프를 그리기 전 항상 다음 질문을 먼저 한다.

1. 무엇을 보여주고 싶은가?
2. 그것은 아래 중 무엇인가?
   - 비교
   - 변화
   - 관계
   - 분포

이 질문에 답이 나오면 그래프 선택은 자연스럽게 결정된다.

---

## 3. 그래프 4종 세트 (기본)

- **막대그래프 (bar)**  
  → 범주 간 비교

- **선그래프 (line)**  
  → 시간에 따른 변화

- **산점도 (scatter)**  
  → 두 변수 간의 관계 (A vs B)

- **히스토그램 (histogram)**  
  → 값의 분포 (어느 구간에 몰려 있는지)

대부분의 시각화 문제는 이 네 가지 안에서 해결된다.

---

## 4. 기본 코드 패턴

```python
df["열이름"].plot()
```

또는

```python
df.plot(x="기준열", y="값열")
```

열을 선택하지 못하면 그래프를 그릴 수 없다.

---

## 5. 그래프에 반드시 포함해야 할 요소

- 제목(title)
- x축 / y축 이름
- 말로 된 해석 한 문장

그래프는 그림이 아니라 **의미 전달 도구**다.

---

## 핵심 정리

> 열을 고른다 → 그래프를 고른다 → 한 문장으로 설명한다

---

## 실습 1. 막대그래프 — 비교

과목별 점수를 비교하고 싶을 때 사용한다.

```python
import pandas as pd

df = pd.DataFrame({
    "과목": ["국어", "수학", "영어"],
    "점수": [80, 95, 70]
})
```

```python
df.plot(x="과목", y="점수", kind="bar")
```

해석 예시:
- 과목별 점수를 비교한 결과, 수학 점수가 가장 높다.

---

## 실습 2. 선그래프 — 변화

데이터에 시간의 흐름이 있으면 선그래프를 사용한다.

```python
df = pd.DataFrame({
    "날짜": ["1일", "2일", "3일", "4일"],
    "매출": [100, 130, 120, 160]
})
```

```python
df.plot(x="날짜", y="매출", kind="line")
```

해석 예시:
- 매출은 2일 이후 감소했다가 4일에 다시 증가했다.

---

## 실습 3. 산점도 — 관계

산점도는 **A가 변할 때 B도 함께 변하는지**를 확인할 때 사용한다.

```python
import matplotlib.pyplot as plt

plt.scatter(df["공부시간"], df["점수"])
```

해석 예시:
- 공부시간이 증가할수록 점수가 전반적으로 증가하는 경향을 보인다.
- 정확한 수치보다 **경향**이 중요하다.

---

## 실습 4. 히스토그램 — 분포

히스토그램은 값이 어느 구간에 많이 몰려 있는지를 확인할 때 사용한다.

해석 예시:
- 점수는 70~80점 구간에 가장 많이 분포되어 있다.

---

## 시각화를 위한 데이터 가공 도구 요약

- **groupby**  
  범주별 묶기, 요약 (막대그래프 전 단계)

- **diff / pct_change**  
  변화량 / 변화율 (선그래프 보조)

- **rolling**  
  이동 평균, 추세선

- **누적 계산**  
  누적 값 확인

- **ewm**  
  지수가중 (중요도 낮음)

---
