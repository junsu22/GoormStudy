## 1. 변수 (Variable)

### 변수명 규칙

**사용 가능**
- 알파벳 (대소문자 구분)
- 숫자 (맨 앞 사용 ❌)
- `_` (특수문자는 언더바만 허용)

**사용 불가**
- 숫자로 시작 ❌
- 예약어 ❌  
  (`def`, `if`, `del`, `return`, `import` 등)

**기타**
- 한글 변수명 가능하나 비추천
- 대소문자 구분 (`age ≠ Age`)

---

## 2. 데이터 타입 (Data Type)

### bool (Boolean)

- 참 / 거짓을 나타내는 타입
- 값은 반드시 **대문자 사용**
- 내부적으로 `True = 1`, `False = 0`

```python
print(type(True))
```

출력 결과:
```text
<class 'bool'>
```

---

## 3. 여러 줄 문자열 (트리플 따옴표)

트리플 따옴표(`'''` 또는 `"""`)를 사용하면  
줄바꿈(엔터)을 포함한 문자열을 작성할 수 있으며,  
작성한 형태 그대로 출력된다.

```python
word1 = '''줄바꿈 실습
김준수입니다.
이어서 출력'''
print(word1)
```

출력 결과:
```text
줄바꿈 실습
김준수입니다.
이어서 출력
```

---

## 4. 타입 확인 (type)

`type()` 함수는 값의 **자료형을 반환**한다.  
출력하려면 `print()`로 감싸야 한다.

```python
a = 10
print(type(a))
```

출력 결과:
```text
<class 'int'>
```

---

## 5. 정해지지 않은 값 (None)

`None`은 아직 값이 정해지지 않았음을 의미하며,  
초기화 용도로 자주 사용된다.

```python
b = None
print(b)
```

---

## 6. 리스트 append 사용

`append()`는 **리스트 전용 메서드**이며,  
`int`, `tuple`에서는 사용할 수 없다.

```python
mylist = [1]
mylist.append(2)
mylist.append(5)

print(mylist)
```

출력 결과:
```text
[1, 2, 5]
```

### 튜플 참고
- 튜플은 콤마(`,`)로 생성 가능
- 값 변경 불가 (immutable)
- 현재 단계에서는 리스트로 충분하다고 판단하여 패스

## 7. 리스트 메서드 정리 (정렬 · 추가 · 삭제 · 개수)

### sort()

- 원본 리스트 변경 ⭕
- 반환값 없음
- 실제 데이터 정렬
- `reverse=True` 옵션 사용 시 정렬 결과를 반대로 뒤집음

```python
mylist = [1, 9, 2, 5, 6, 3, 8]
mylist.sort(reverse=True)
print(mylist)
```

출력 결과:
```text
[9, 8, 6, 5, 3, 2, 1]
```

---

### sorted()

- 원본 리스트 변경 ❌
- 새로운 리스트 반환
- 결과 확인용

```python
mylist2 = [1, 9, 2, 5, 6, 3, 8]

print(sorted(mylist2))
print(mylist2)
print(sorted(mylist2, reverse=True))
```

출력 결과:
```text
[1, 2, 3, 5, 6, 8, 9]
[1, 9, 2, 5, 6, 3, 8]
[9, 8, 6, 5, 3, 2, 1]
```

---

### split()

- 문자열을 특정 구분자를 기준으로 나누어 리스트로 반환

```python
a = '01-img-png'
result = a.split('-')
print(result)
```

출력 결과:
```text
['01', 'img', 'png']
```
