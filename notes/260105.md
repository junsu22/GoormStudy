# 모듈 가져오는 방법은 여러가지 
1. 공구통 > 망치 > 전체를 가져오는방법
2. 공구통 > 플라이어 만 가져오는 방법
3.
```python from 공구통 import *```
*사용하면 공구통 뺴고 안에 있는 것만 가져올 수 있는 방법도 있다. .


 모듈은 .py 그 자체. 모듈이라고 부르는게 더 정확하다. 
 코드를 포함하는 파일
 (함수,클래스,변수 등을 가져올 수 있다. )

---

```python
# mymod.py
var = 10

def myfunc():
    print("hello")
```

# 다른 파일 
```python
import mymod 

print(mymod.var) 
mymod.myfunc() # 접근, mymod에 포함된 myfunc함수를 바인딩. ()를 붙여주면 함수가 호출 된다. 
```
점(.)을 찍으면 해당 모듈에 있는 변수, 함수, 클래스 에 접근 할 수 있다.
프로젝트를 할때 모듈 단위로 하게 될 것임. 중요한 것이니 꼭 익힐 것.

```python 
import tkinter
tkinter.widget = tkinter.Label(None, text = 'I Love Python!')
tkinter.widget.pack()
# 매번 써주기 번거로움

from tkinter import *
widget = Label(None, text = 'I Love Python!')
widget.pack() # < 모듈내의 이름을 콕 찝어 가져오는 방법 , 이게 좀 더 편한 방법.
```
