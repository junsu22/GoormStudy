# 클래스, 객체 

클래스는 변수와 함수를 묶어 놓은 설계도

클래스 = 붕어빵 틀 (객체를 만들기 위한 틀, 설계도)</br>
객체 = 붕어빵 (실제 사용대상, 하나의 클래스로 여러개의 객체를 만들 수 있다. 다른값을 가질 수 있다.)
비유 </br>
틀(클래스)로 붕어빵(객체) 여러개 찍어내기 가능 . 팥,슈크림 속( 값 )</br>

설계도 (클래스) 객체 (제품)</br>
init  객체가 실행될때 자동으로 실행 되는 함수. </br>

---
```class Person:
    def __init__(self, name):
        self.name = name
    def say_hi(self):
        print("안녕하세요,", self.name)</code>
```

---
person 클래스 이름 </br>
init 객체가 생성될때 자동으로 실행 되는 함수</br>
self.name 객체가 가지는 변수, self는 자기 자신을 가리킴.</br> 
say_hi() 객체가 사용할 수 있는 기능 </br>


객체 생성

```
p1 = person("준수")
p2 = person("민수")

p1.say_hi()
p2.say_hi()
```

안녕하세요, 준수
안녕하세요, 민수

객체.기능()
p1.say_hi()

person 이라는 설계도 
p1 은 설계도로 만든 객체(그 안에 name = "준수") 가 들어있음.
say_hi()는 기능
