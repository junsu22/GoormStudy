■ 정렬 (엑셀 방식과 유사)

1) sort_values : 값 기준 정렬
- by : 기준 컬럼명 (ex. 'col3')
- axis : 0=row, 1=column
- ascending : True(오름차순) / False(내림차순)
- na_position : 'last' (NaN 뒤로) / 'first'
- ignore_index : True → 인덱스 0,1,2 재생성
- key : lambda 사용 (정렬 전 값 가공)
- inplace : True → 원본 변경

※ 타입 섞이면 정렬 오류 발생

예)
5×3 데이터
row 5 / column 3
col3 기준 정렬
NaN → 뒤로 보냄

--------------------------------------------------

2) sort_index : 인덱스 기준 정렬
- 멀티 인덱스에서 많이 사용
- 파라미터 : axis, level, ascending, inplace, kind

level
- level 0 : row 기준
- level 1 : value 기준

level=[1,0]
ascending=[False, True]
→ level 1 먼저 정렬 후 level 0 정렬 (순차적)

--------------------------------------------------

3) 상위 / 하위 데이터
- nlargest(n, col)
- nsmallest(n, col)
- head(n) / tail(n)

--------------------------------------------------

■ 중복 처리
- keep 인수
  · 'first' : 처음 값 유지
  · 'last' : 마지막 값 유지
  · False : 중복 전부 표시

--------------------------------------------------

■ 결합 (combine / join / merge)

1) combine / combine_first
- 셀 단위 결합
- func 적용
- fill_value : NaN 대체값 (예: 9)
- overwrite : 기존값 덮어쓸지 여부

combine_first
- NaN만 다른 값으로 채움

--------------------------------------------------

2) join (실무에서 많이 사용)
- on : 기준 컬럼
- how : left(기본), right, inner, outer
- suffix : 컬럼명 중복 처리
- right는 df2 인덱스 기준

outer : 합집합

--------------------------------------------------

3) merge
- 두 DataFrame 병합 (SQL join 유사)
- join보다 세부 설정 가능

옵션
- suffixes : ('_x','_y')
- indicator : 병합 정보 컬럼 생성
- validate : 병합 방식 검증
  · '1:1', '1:m', 'm:1'
  · 조건 안 맞으면 에러 발생

인덱스 기준으로 병합 left_index / right indx 
열과 인덱슬르 혼합하여 병합

■ 조언

■ merge / join 보충

- how='left' : 왼쪽(df1) 기준
- how='right' : 오른쪽(df2) 인덱스 기준
- indicator : 병합 정보 출력
- validate='1:m' : 조건 안 맞으면 merge 오류 발생

- how='cross'
  · 모든 경우의 수 출력 (곱집합)
  · 행렬곱 개념
  · 실무에서는 잘 안 씀

--------------------------------------------------

■ align (65p)
- 객체 병합 X, 정렬 + 결측치 제어
- 기준에 맞춰 정렬
- 결과는 튜플 형태로 반환

옵션
- method
- limit
- fill_axis

--------------------------------------------------

■ 브로드캐스트
- 저차원 → 고차원에 맞춰 연산
- 겹치는 구간 기준으로 계산됨

(left = df1 / right = df2)
서로 다른 범위지만
겹치는 영역 기준으로 맞춰진다고 이해

(colab 실습 예제는 순차라 이해 어려웠음)

■ fill_value
- 원하는 값으로 결측치 변경
- 예: 다른 값들 전부 'x'로 변경

ffill / bfill
- 결측치 보정
- ffill : 앞 값으로 채움
- bfill : 뒤 값으로 채움

limit
- 몇 개까지만 채울지 제한

fill_axis
- 0 : 세로
- 1 : 가로

--------------------------------------------------

■ update
https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.update.html

- 말 그대로 업데이트 (덮어쓰기)
- overwrite / filter_func / errors 만 보면 됨

overwrite=True
- df2 값을 df1에 덮어씀
- NaN 제외하고 덮어쓰기

overwrite=False
- NaN은 덮어쓰지 않음

filter_func
- 조건에 맞는 값만 업데이트
- 예: x == 6 인 경우만 업데이트

--------------------------------------------------
