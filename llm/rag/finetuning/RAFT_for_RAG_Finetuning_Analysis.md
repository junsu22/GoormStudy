# RAFT 논문 분석

## 1. 문제 정의 (Background)

기존 RAG는 검색된 문서의 품질에 의존하기 때문에, 관련 없는 정보가 포함될 경우 환각(Hallucination)이 발생하는 문제가 있다.

---

## 2. 기존 방법의 한계

기존 방식은 검색 결과를 그대로 활용하는 구조로, 모델이 문서를 충분히 이해하지 못하고 단순히 결합하는 수준에 머무른다는 한계가 있다.

---

## 3. 제안 방법 (Proposed Method)

RAFT는 이러한 문제를 해결하기 위해, 검색 단계가 아닌 **모델 학습 단계**에서 접근한다.

질문(Query), 문서(Document), 정답(Answer)을 하나의 데이터셋으로 구성하여 파인튜닝함으로써, 모델이 문서를 기반으로 답변을 생성하도록 학습시킨다.

---

## 4. 핵심 아이디어

기존 RAG가 입력 데이터를 정제하는 방식이라면,
RAFT는 모델 자체를 학습시켜 문서 활용 능력을 개선하는 접근이다.

---

## 5. 결론 (Conclusion)

RAFT는 데이터셋 기반 학습을 통해 기존 RAG의 한계를 보완하며, 보다 정확한 근거 기반 답변 생성을 가능하게 한다.

---

## 한 줄 정리

RAG의 성능을 개선하는 방법은 검색 개선뿐 아니라, 모델 학습 방식에서도 접근할 수 있다.
