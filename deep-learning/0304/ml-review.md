# 선형회귀 (Linear Regression)
- 데이터를 반영하는 가장 적절한 선을 긋는다.

직선 을 표현 하는 식
수학관점> (기울기, 절편)
y = ax + b

머신러닝 관점> (가중치,편향)
y= wx + b 
w (가중치)와 b(편향) 의 값에 따라 표현되는 직선이 달라진다.

결론 : 선형회귀는 결국 데이터를 적절히 반영하는 w, b 를 찾는 작업이다.

# MSE
수치를 표현 하기 위해서는 오차(Error)를 도입해야 한다.
목표: 오차를 최소로 만드는 w, b 를 찾아야 한다. 


방법 1 : 오차 모두 더하기  > (-2) + 10 .. + (-5) = ?
※ 음수 오차, 양수오차가 섞여 제대로 된 오차의 양을 구할 수 가 없다. 

방법 2 :  MSE (Mean Square Error)
2-1. 제곱 오차 : 모든 오차를 제곱한 후 더한다. 
(-2)^2 + 10^2 ...+(-5)^2 = 210
2-2 . 제곱오차에서 나온 값을 데이터의 개수(n) 으로 나누게 되면 오차의 평균을 얻을 수 있다.
이를 평균 제곱오차 (MSE) 라고한다.
>>> 이 평균 제곱 오차가 최소가 되는 w 와 b 를 찾아내는 것이 목표이다.

# Cost Function(비용함수)

※ 셋 다 같은 의미 임. 

NN 에서는 기본적으로 cost function을 최소화 하는 w 와 b 를 찾는 것이 목적이다.

선형 회귀를 포함한 인공신경망에서는 비용함수를 최소화 하는 매개변수를 찾는 것이 목적.
이때 사용되는 알고리즘을 옵티마이저 (Optimizer)라고 함.

경사 하강법은 대표적인 옵티마이저 알고리즘이다. 

# Gradient Desent (경사하강법)
w(가중치)가 지나치게 높거나 낮을때, b(편향)이 지나치게  높거나 낮을때 오차가 증가하게 된다.

경사 하강법은 접선의 기울기 개념을 사용하게 된다.
경사 하강법은 최적의 값을 향해 매개 변수를 반복 업데이트 한다.

비용함수(costfuction)을 미분 하게 되면 접선의 기울기를 얻을 수 있다.
 
 음수(negative) - 0 - 양수(postive)  (U 자 형 그래프)

다음 w값 = 현재의 w값 - 접선에서의 기울기

미분하여 현재w 에서 접선의 기울기를 구한다. 
접선의 기울기가 낮은 방향으로 w 의 값을 변경하고 이 과정을 반복한다.

# 인공신경망( NN ) 설계
1. 전처리 : 학습에 필요한 데이터의 전처리를 수행한다
2. 모델링 : 모델을 정의한다.
3. 컴파일 : 모델을 생성한다.(어떤 공식(ex.mse)를 사용하고 , 어떤 엔진(ex.sgd)으로 w,b를 수정할지 결정 단계)
4. 학습 : 모델을 학습(fit)

용어 정리 : 
Dense : 입출력 차원 작성 모듈
sgd : 경사하강법
mse : 평균제곱오차
fit : 학습을 의미 피트인
epochs : w, b 업데이트 횟수 (ex. epochs= 100 : w, b 를 수정하는 방법을 100번한다. )

# 로지스틱 회귀 
- 회귀 모델 이지만 . 실제로는 이진 분류 모델 
- 두개의 선택지 중에서 정답을 고르는 문제에 사용하는 모델
(ex.합격을 1 , 불합격을 0 으로 가정해서 그래프를 그리면 )
단호한 그래프가 출력된다 . 

1, 0 사이의 값이 없어 직선으로 그리기 어렵기 때문에 이를 반영하는 S 자 모양의 그래프가 필요하다.

해결 방법 : 시그모이드 함수 (커브가 가능해짐)
시그모이드 함수는 입력값이 커지면 1 에 수렴 하고 작으면 0 에 수렴한다. 

0부터 1 까지의 값을 가지는데 출력값이 0.5 이상이면 1(True), 미만이면 0 (False)로 만들어 
이진분류 문제로 사용이 가능해진다. < 임계값

- 로지스틱 회귀는 비용함수로 평균 제곱 오차 (MSE)를 사용하지 않는다.
만약 비용함수로 MSE 를 사용할 경우 굴곡이 심한 그래프를 얻게 된다.(학습이 제대로 안된다.)

- 비용함수로 크로스 엔트로피 함수를 사용하여야 한다.
정답과 반대로 예측을 할수록 오차가 기하급수적으로 커진다. 빠르게 업데이트를 하고 맞는 방향을 예측한다.
로그를 사용하여 경사를 가파르게 만든다. 경사가 급하니 가장 아래 까지 빠르게 내려갈 수 있다. (빠름)

중요 : 
선형 회귀 가설 : y = wx  + b
선형회귀 손실 : MSE
연속적인 값 (온도)


로지스틱 회귀 가설 : y = sigmoid(wx + b)
로지스틱 회귀 손실 : Cross-entropy
1 또는 0 (합/불)

# 로지스틱 회귀 vs 소프트맥스 회귀
- 로지스틱 회귀는 이진분류 문제에 사용
- 소프트맥스 회귀는 다중 클래스 분류 문제에 사용


- 로지스틱회귀는 가설에 sigmoid 함수 사용
- 소프트맥스회귀는 가설에 softmax 함수 사용

- 소프트맥스 회귀는 각 카테고리를 원-핫 인코딩 (숫자 화)
ex. 개 = [ 1, 0, 0] , 고양이 = [0, 1, 0], 새 = [0, 0, 1]

- 두함수 모두 손실 함수는 크로스 엔트로피 함수 사용

# N - gram 모델 (단어나열)
- n 개의 연속적인 단어 나열을 의미하며 n 은 사용자가 정하는 값이다.
- 이전 단어들이 주어졌을때 다음 단어의 등장확률의 추적을 앞의 n -1 개의 단어에만 의존한다. 
[나는][밥을][먹는다]

- bigram 모델 (이전 단어)
오직 이전 단어에만 의존한다. 
[나는 밥을] <- 앞에 "밥을" 만 보고 예측 [밥을 먹는다]

N 이 클 수록 더 많은 단어들을 참고해 다음 단어 들을 예측. 
적절한 n을 잘 설정 해줘야 한다.
