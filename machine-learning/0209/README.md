# 1️⃣ 머신러닝

최근 각광받고 있지만, 사실 오래된 개념이다.

사람이 직접 규칙을 코딩하는 것이 아니라  
**데이터를 통해 패턴(규칙)을 학습하는 방식**이다.

예시:
팀장은 직원이 어떻게 작업하는지 하나하나 지시하지 않는다.  
목표와 방식만 제시하고, 결과를 보고 판단한다.

---

# 📌 ETP 정의 (Arthur Samuel)

머신러닝은 다음 조건을 만족할 때 학습한다고 말한다.

E : Experience (경험)  
→ 학습에 사용되는 데이터

T : Task (과제)  
→ 모델이 수행해야 하는 일

P : Performance measure (성능지표)  
→ 얼마나 잘했는지 평가하는 기준

예시 (암 분류 문제):
- E : 종양 데이터
- T : 악성/양성 분류
- P : 정확도, F1-score 등

------------------------------------------------------------------------

# 2️⃣ 지도학습 (Supervised Learning)

정답(label)을 미리 제공하고 학습시키는 방식이다.

예시:
단어카드 → "이건 강아지야"

지도학습은 크게 두 가지로 나뉜다.

---

## ✔ Regression (회귀)

- 출력값(output)이 연속적인 값
- 예: 집값, 매출, 평수

입력(X) → 실수값 예측(Y)

---

## ✔ Classification (분류)

- 출력값이 범주형(카테고리)
- 예: 악성 / 양성, 합격 / 불합격, 스팸 / 정상 메일

핵심:
입력 데이터(X)를 기반으로  
어떤 범주(Y)에 속하는지 예측하는 문제

예시 (암 진단):

입력(X)
- 종양 크기
- 나이
- 세포 밀도
- 모양 등

출력(Y)
- 악성(1)
- 양성(0)

의사는 한 가지 기준만으로 판단하지 않는다.  
여러 feature의 패턴을 종합하여 판단한다.

---

# 3️⃣ 비지도학습 (Unsupervised Learning)

정답(label)이 제공되지 않는 학습 방식이다.

데이터 내부의 구조나 관계를 스스로 찾아낸다.

---

## ✔ 클러스터링 (Clustering, 군집화)

- 비슷한 데이터끼리 묶는 작업(유사)
- 변수 간 관계를 기반으로 구조 도출

예:
논문 데이터에서 유사한 주제끼리 묶기

---

## ✔ 비클러스터링 예시

참고 예시: 칵테일 파티 문제, PCA(차원축소)

- 여러 사람의 목소리 속에서
- 특정 사람의 목소리만 분리

→ 사람의 뇌 구조와 유사한 방식
→ 대표적인 비지도학습 사례



# 4️⃣ 선형회귀(Linear Regression)


연속적인 값을 예측하는 지도학습 방법이다.
예) 집값예측, 매출예측, 온도예측

입력x 와 출력 y 사이의 관계를 가장 잘 설명하는 **직선**을 찾는것

# 단변량 선형회귀 (Univariate Linear Regression)
feature(입력 변수)가 1개 인 경우
ex. 집의 평수 →  집값


# 다변량 선형회귀 
집의 평수, 화장실, 복층구조 등 → 집값
feature(입력변수)가 2개 이상인 경우



정리:
단변량과 다변량의 차이는
입력 변수(feature)의 개수 차이이다.


# 단변량 실습 코드

### x축 : 입력

# 가설 함수 (Hypothesis)
단변량 가설 함수
h(x) = θ0 + θ1x

다변량 가설 함수
h(x) = θ0 + θ1x1 + θ2x2 + ... + θnxn

---

- θ0 : 절편 (y축과 만나는 값)
- θ1, θ2, ... : 각 feature의 영향력(가중치)
- x : 입력값 (feature)
- h(x) : 예측값


우리가 해야 할 일:
→ θ(가중치)들의 최적값을 찾는 것


Training Example: (x(i), y(i))


------------------------------------------------------------------------

# 5️⃣ Cost Function (비용 함수)

가설 함수가 얼마나 틀렸는지를 수치로 측정하는 함수이다.

오차(Error):
실제값 - 예측값  
(y - ŷ)


---

## ✔ LSE (Least Squares Error)

전체 데이터의 제곱 오차를 모두 더한 값

LSE = Σ (y - ŷ)^2

- 데이터가 많아질수록 값이 커짐
- 단순히 총 오차의 크기

---

## ✔ MSE (Mean Squared Error)

제곱 오차의 평균값

MSE = (1 / m) Σ (y - ŷ)^2

- m : 데이터 개수
- 평균을 사용하여 데이터 수에 영향 받지 않음

---

## ✔ 머신러닝에서 자주 사용하는 형태

J(θ) = (1 / 2m) Σ (y - ŷ)^2

- 2는 미분 시 계산을 단순하게 만들기 위한 수학적 편의

목표: Cost Function J(θ)를 최소화하는  θ(가중치)를 찾는 것

# 6️⃣ Gradient Descent (경사하강법)
등고선에서 가장 낮은(loss 가 최소인 지점)을 찾아가는 최적화 방법
현재 위치에서 기울기(경사)를 계산하고, 내리막 방향으로 조금씩 이동하며 최적값을 찾아간다


# Converting to Tensor
스칼라(숫자 하나, ex.1) > 벡터(숫자 한 줄, ex.[1, 2, 3]) > 매트릭스(숫자 표, ex. 2차원)
> 텐서(모든 걸 포함하는 통합 개념, 3차원 이상도 가능)

데이터를 PyTorch가 쓸 수 있는 텐서 형태로 변환하는 과정.
모델은 텐서만 입력받을 수 있기 때문에 변환이 필수.
