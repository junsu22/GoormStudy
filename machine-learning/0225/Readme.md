## 머신러닝 평가 Metric에 대한 분석

머신러닝 모델의 성능을 평가하기 위해 다양한 평가 지표(Metric)가 사용된다.  
지금까지 실습에서는 Accuracy, MSE, RMSE와 같은 평가 방법을 사용하여 모델 성능을 확인하였다.

- Accuracy : 전체 데이터 중 올바르게 예측한 비율
- Precision : 양성으로 예측한 것 중 실제 양성의 비율
- Recall : 실제 양성 중 모델이 맞게 예측한 비율
- F1-score : Precision과 Recall의 조화 평균



이러한 평가 지표는 모델의 예측 성능을 수치적으로 확인할 수 있도록 도와준다.  
예를 들어 분류 문제에서는 Accuracy를 통해 전체 예측 정확도를 확인할 수 있고,  
회귀 문제에서는 MSE나 RMSE를 통해 예측값과 실제값 사이의 오차를 측정할 수 있다.

하지만 하나의 평가 지표만으로 모델 성능을 판단하기에는 한계가 있을 수 있다.  
특히 데이터가 불균형한 경우 Accuracy만으로는 모델 성능을 정확하게 평가하기 어렵기 때문에  
Precision, Recall, F1-score와 같은 다양한 평가 지표를 함께 고려하는 것이 중요하다.
