# 🤖 Groq + LLaMA 실습 — 멀티턴 챗봇 만들기

> LLM API를 처음 사용해보면서,  
> **AI 모델이 어떻게 대화를 이어가는지 전체 흐름을 이해하기 위한 실습**을 진행했다.

이번 실습에서는 Groq API와 Meta의 **LLaMA 3.3 70B** 모델을 사용해  
이전 대화를 기억하며 이어가는 **멀티턴 챗봇**을 구현했다.

---

## 📌 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 목적 | LLM API 입문 — 챗봇 전체 흐름 이해 |
| 모델 | LLaMA 3.3 70B (Meta) |
| 플랫폼 | Groq (무료 티어) |
| 환경 | Python 3.13 / Windows |
| 핵심 기능 | 시스템 프롬프트 + 멀티턴 대화 |

---

## 🧠 LLaMA란?

LLaMA는 **Meta(페이스북)** 가 만든 오픈소스 AI 언어 모델이다.

| | GPT | LLaMA |
|---|---|---|
| 만든 곳 | OpenAI | Meta |
| 공개 여부 | 비공개 | 오픈소스 |
| 사용 비용 | 유료 API | 무료 가능 |

이번 실습에서는 **Groq** 플랫폼을 통해 LLaMA를 무료로 사용했다.  
Groq은 오픈소스 모델을 매우 빠르게 실행해주는 추론 플랫폼이다.

---

## ⚙️ 전체 챗봇 동작 흐름
```
사용자 입력
→ messages 리스트에 추가
→ Groq API로 전송 (대화 기록 전체)
→ LLaMA 모델이 답변 생성
→ 답변을 messages 리스트에 추가
→ 반복
```

---

## 🔤 핵심 개념 — messages 구조

LLM API는 대화를 **role + content** 형태로 관리한다.

| role | 역할 |
|---|---|
| system | AI에게 역할/성격 부여 |
| user | 사용자 입력 |
| assistant | AI 답변 |

---

## 💬 시스템 프롬프트란?

AI에게 **역할을 부여**하는 설정값이다.  
시스템 프롬프트에 따라 동일한 모델도 전혀 다른 성격으로 동작한다.

---

## 🤖 멀티턴이란?

**이전 대화를 기억하면서 이어가는 것**이다.  
매번 **전체 대화 기록을 API에 넘겨주는 것**이 핵심이다.
