## 🤖 머신러닝이란?

기존 프로그래밍은 사람이 규칙을 직접 만들어 기계에게 알려줬다.

```
a = 7, b = 5 → result = 12  # 사람이 "더해"라고 알려줌
```

머신러닝은 반대다. **데이터를 많이 주고, 기계가 패턴을 직접 찾게 한다.**

```
input 2, 7  → result 9
input 4, 8  → result 12
input 1, 5  → result 6
# 기계가 스스로 "더하기"를 찾아낸다
```

### 머신러닝의 3가지 기본 과정
1. 학습하고자 하는 **가설** 세우기
2. 성능을 측정하는 **손실함수(loss function)** 정의
3. 손실함수를 최소화할 수 있는 **학습 알고리즘** 설계

---

## 📈 선형회귀 (Linear Regression)

데이터를 반영하는 **가장 적절한 선을 긋는** 모델

| 관점 | 식 | 용어 |
|---|---|---|
| 수학 | y = ax + b | 기울기, 절편 |
| 머신러닝 | y = wx + b | 가중치(w), 편향(b) |

> **결론 : 선형회귀는 결국 데이터를 적절히 반영하는 w, b를 찾는 작업이다.**

---

## 📉 MSE (평균 제곱 오차)

오차를 단순히 더하면 음수/양수가 섞여 제대로 된 오차를 구할 수 없다.

**해결 → MSE (Mean Square Error)**

1. 모든 오차를 **제곱**해서 더한다 → `(-2)² + 10² + (-5)² = 210`
2. 데이터 개수 n으로 나눠 **평균**을 구한다

> **이 평균 제곱 오차가 최소가 되는 w와 b를 찾는 것이 목표**

---

## 🎯 비용함수 (Cost Function)

실제값과 예측값의 오차를 나타내는 식

- 목적함수 (Objective function)
- 비용함수 (Cost function)
- 손실함수 (Loss function)

> ※ 셋 다 같은 의미

**NN에서의 목적 = cost function을 최소화하는 w와 b를 찾는 것**

이때 사용하는 알고리즘을 **옵티마이저(Optimizer)** 라고 한다.

---

## ⛰️ Gradient Descent (경사하강법)

대표적인 옵티마이저 알고리즘

- 비용함수를 **미분**하면 접선의 기울기를 얻을 수 있다
- 기울기가 낮은 방향으로 w값을 반복 업데이트

```
다음 w값 = 현재 w값 - 접선의 기울기
```

음수 → 0 → 양수 (U자형 그래프)에서 가장 아래(최솟값)를 향해 내려간다.

## 🧱 Keras & 인공신경망 설계

Keras는 TensorFlow의 하이레벨 API

```python
from tensorflow.keras.layers import Dense
```

### NN 설계 4단계
1. **전처리** : 데이터 전처리
2. **모델링** : 모델 정의
3. **컴파일** : 공식(ex. mse)과 엔진(ex. sgd) 결정
4. **학습** : `model.fit()`

### 용어 정리
| 용어 | 설명 |
|---|---|
| Dense | 입출력 차원 설정 모듈 `Dense(3, input=4)` |
| sgd | 경사하강법 |
| mse | 평균제곱오차 |
| fit | 학습 |
| epochs | w, b 업데이트 횟수 |
| activation function | 출력에 적용할 함수 |
| adam | sgd의 발전된 형태, 학습률 자동 조정 |

## 🔀 로지스틱 회귀 (Logistic Regression)

- 회귀 모델이지만, 실제로는 **이진 분류 모델**
- 두 개의 선택지 중 정답을 고르는 문제에 사용

0과 1 사이에 값이 없어 직선으로 표현하기 어렵다 → **S자 곡선이 필요**

### 해결 → 시그모이드 함수
- 입력값이 커지면 **1에 수렴**, 작아지면 **0에 수렴**
- 출력값 `≥ 0.5` → 1 (True), `< 0.5` → 0 (False) ← **임계값**

### 왜 MSE를 안 쓰냐?
MSE 사용 시 굴곡이 심한 그래프 → **로컬 미니멈에 빠져 학습이 제대로 안 된다**

### 해결 → Cross-entropy
- 정답과 반대로 예측할수록 오차가 **기하급수적으로** 커짐
- 로그를 사용해 경사를 가파르게 만들어 **빠르게 수렴**

### ⭐ 중요 비교

| | 선형회귀 | 로지스틱 회귀 |
|---|---|---|
| 가설 | y = wx + b | y = sigmoid(wx + b) |
| 손실함수 | MSE | Cross-entropy |
| 출력 | 연속적인 값 (온도) | 1 또는 0 (합/불) |

## 🌈 소프트맥스 회귀 (Softmax Regression)

- **다중 클래스 분류** 모델 (3개 이상 선택지)
- 각 클래스에 대해 확률 계산, **전체 합은 1(100%)**
- 가장 높은 확률의 클래스를 정답으로 선택

### 행렬곱과 가중치
```
입력 차원 × 출력 차원 = 가중치 개수
4차원 → 3차원 = 가중치 12개
편향(bias) = 출력 차원만큼 → 3개
총 파라미터 = 12 + 3 = 15개
```

### 로지스틱 vs 소프트맥스 비교

| | 로지스틱 회귀 | 소프트맥스 회귀 |
|---|---|---|
| 문제 유형 | 이진 분류 | 다중 클래스 분류 |
| 가설 함수 | sigmoid | softmax |
| 손실 함수 | Cross-entropy | Cross-entropy |

**원-핫 인코딩** : 각 카테고리를 숫자 벡터로 표현
```
개       = [1, 0, 0]
고양이   = [0, 1, 0]
새       = [0, 0, 1]
```

## 🧠 NN (신경망) 이해하기

소프트맥스에서 다룬 행렬곱과 동일한 개념
> 입력 차원 × 출력 차원 = 가중치 개수, bias는 출력 차원만큼

### 은닉층 (Hidden Layer)
- 입력층과 출력층 사이에 추가된 층
- **층이 깊어질수록 더 복잡한 패턴을 학습할 수 있다**

## 📝 Text Classification (텍스트 분류)

주어진 텍스트가 이미 정의된 카테고리 중 어디로 분류되어야 하는지 예측하는 작업
자연어 처리 작업 중 수요가 높은 기본적인 작업

**활용 예시**
- 언론사 뉴스 자동 카테고리 분류
- 스팸 분류
- 뉴스 종목 분류 (어떤 종목의 뉴스인지 판별해 해당 게시판으로 분류)
- 사용자 리뷰 감성 분류
- 챗봇 문의 유형 분류기 (환불, 주문, 건의)

## 💬 언어 모델 (LM, Language Model)

단어 시퀀스에 확률 P를 할당. **더 그럴듯한 문장을 만들기 위해 사용**

```
기계번역 : P(나는 버스를 탔다) > 나는 버스를 태운다
음성인식 : P(나는 메롱을 먹는다) < P(나는 메론을 먹는다)
오타교정 : P(선생님이 달려갔다) > P(선생님이 잘려갔다)
```

## 🔤 N-gram 모델

- n개의 연속적인 단어 나열, **n은 사용자가 정하는 값**
- 다음 단어 예측 시 앞의 **n-1개 단어에만 의존**

```
1-gram : [나는] [밥을] [먹는다]
2-gram : [나는 밥을] [밥을 먹는다]
```

**bigram (n=2)** : 오직 이전 단어 1개에만 의존
```
[나는 밥을] ← "밥을"만 보고 다음 단어 예측 → [밥을 먹는다]
```

> N이 클수록 더 많은 단어를 참고해 다음 단어를 예측. 적절한 n 설정이 중요.

## 🗝️ NNLM 워드 임베딩

임베딩을 이용하면 **벡터 간 유사도**를 얻을 수 있다.

### 희소 문제 해결
> **희소 문제** : 훈련 데이터에 없는 단어 조합은 확률을 0으로 처리해버리는 문제

워드 임베딩으로 비슷한 의미의 단어끼리 가깝게 표현

```
귀여운  ~ 사랑스러운
강아지  ~ 고양이
좋아해  ~ 사랑해
```

→ 훈련 데이터에 없던 시퀀스도 생성 가능

```
"귀여운 강아지 좋아해" ✅
```
