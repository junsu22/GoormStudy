## 🧠 나이브 베이즈(Naive Bayes)란?

나이브 베이즈는 **베이즈 정리(Bayes Theorem)** 를 기반으로 확률을 계산해 분류하는 알고리즘이다.

우리가 구하고 싶은 값은 다음이다.

> P(스팸 | 단어들)

즉,

"이 단어들이 포함된 메시지가 스팸일 확률은 얼마인가?" 를 계산하는 방식이다.

공식:

```
P(스팸 | 단어들)
= P(단어들 | 스팸) × P(스팸) / P(단어들)
```

### 왜 “Naive(순진한)”인가?

단어 간 관계를 고려하지 않고 **서로 독립이라고 가정**하기 때문이다.

예를 들어 현실에서는:

- 지각하는 학생 → 숙제 안 해올 확률 높음

하지만 나이브 베이즈는:

> "지각이랑 숙제는 서로 별개야."  
> 라고 가정하고 각각 따로 확률을 계산한다.

이 단순한 가정 덕분에 계산이 매우 빠르고, 텍스트 분류에서 강력한 성능을 보인다.

## 🔤 텍스트를 숫자로 바꾸기 — TF-IDF

머신러닝 모델은 문장을 그대로 이해하지 못한다.  
그래서 문장을 숫자로 변환해야 한다.

이번 실습에서는 **TF-IDF(Vectorization)** 를 사용했다.

### TF-IDF 역할

- 단어 등장 빈도(TF)
- 전체 문서에서의 희소성(IDF)

을 함께 고려해 **단어 중요도 가중치**를 만든다.

특징:

- 이진 데이터가 아닌 **소수점 가중치**
- 중요한 단어일수록 높은 값

```python
tfidf = TfidfVectorizer(
    stop_words="english",
    max_features=5000
)
```

## 🤖 모델 학습 — Naive Bayes

텍스트를 숫자로 변환한 뒤 모델을 학습한다.

```python
nb_model = MultinomialNB()
nb_model.fit(X_train_tfidf, y_train)
```

모델은 학습 과정에서 다음과 같은 패턴을 학습한다.

> "이 단어는 스팸 메시지에서 자주 등장하네."

### 해석

혼동행렬을 통해 모델의 예측 특성을 보다 명확하게 확인할 수 있었다.

- 정상 메시지(ham)는 965건 모두 정상으로 분류되어 오탐(False Positive)이 발생하지 않았다.
- 반면 스팸 메시지 중 30건은 정상 메시지로 분류되어 일부 스팸을 놓치는 경우가 있었다.
- 스팸 메시지 120건은 정확하게 탐지되었다.

즉, 이 모델은 정상 메시지를 스팸으로 잘못 판단하지 않는 대신,
일부 스팸을 놓치는 **보수적인 분류 성향**을 보였다고 해석할 수 있다.
