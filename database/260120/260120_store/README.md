# 상권 데이터와 인구 데이터 조인 분석

## 1. 데이터 개요
- 상권 데이터: 상가업소정보
- 인구 데이터: 주민등록 인구 및 세대 현황
- 목적: 지역별 매장 수와 인구 수를 함께 조회

## 2. 분석 전략
- 시도명 + 시군구명을 결합하여 지역 기준 생성
- 상권 데이터에서 특정 브랜드(공차) 매장 수 집계
- 인구 데이터의 행정구역과 문자열 매칭을 통해 조인

## 3. 조인 SQL
```sql
SELECT 시도명, 시군구명, 매장수, 인구수
FROM
  (SELECT 시도명, 시군구명, COUNT(*) AS 매장수
   FROM 상가업소정보_202512
   WHERE 시도명 IN ('서울특별시', '경기도', '인천광역시')
     AND 상호명 LIKE '공차%'
   GROUP BY 시도명, 시군구명) AS 매장,
  (SELECT 행정구역, "2025년12월_총인구수" AS 인구수
   FROM 주민등록인구및세대현황) AS 인구
WHERE 인구.행정구역 LIKE 매장.시도명 || ' ' || 매장.시군구명 || '%';
```

## 4. 결과 해석
- 지역별 공차 매장 수와 인구 수를 하나의 결과로 확인
- 서로 다른 공공데이터를 문자열 기반 키로 결합하여 활용

## 5. 정리
- 공공데이터는 공통 키가 없어도 가공을 통해 조인이 가능함을 확인
- JOIN을 통해 지역 단위 비교 분석의 기초를 경험함
