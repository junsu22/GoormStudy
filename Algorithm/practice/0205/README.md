# 📌 Sorting Algorithms 정리

정렬 알고리즘의 개념, 작동 방식, 시간복잡도 및 특징을 정리한 문서입니다.

---

## 1️⃣ Bubble Sort (버블 정렬)

### 📖 개념
거품처럼 큰 값이 점점 뒤로 이동하는 방식의 정렬.

### ⚙️ 작동 방식
- 인접한 두 값을 비교
- 큰 값을 오른쪽으로 이동
- 한 번의 순회가 끝나면 가장 큰 값이 맨 뒤로 이동
- 교환이 더 이상 발생하지 않을 때까지 반복

### ⏱ 시간복잡도
- 평균 / 최악: O(N²)
- 최선: O(N) (이미 거의 정렬되어 있고 교환이 발생하지 않으면)

### 💡 특징
- 안정 정렬
- 구현이 매우 간단
- 큰 데이터에서는 비효율적

---

## 2️⃣ Selection Sort (선택 정렬)

### 📖 개념
매 회전마다 가장 작은 값을 선택해 앞으로 보내는 방식.

### ⚙️ 작동 방식
1. 최솟값 탐색
2. 현재 위치와 스왑
3. 다음 위치에서 반복

### ⏱ 시간복잡도
- 평균 / 최악 / 최선: O(N²)

### 💡 특징
- 불안정 정렬
- 교환 횟수는 최대 N-1번
- 추가 메모리 거의 사용하지 않음

---

## 3️⃣ Insertion Sort (삽입 정렬)

### 📖 개념
정렬된 부분에 새로운 값을 올바른 위치에 삽입하는 방식.

### ⚙️ 작동 방식
- 두 번째 원소부터 시작
- 선택된 값보다 큰 값들을 오른쪽으로 밀기
- 적절한 위치에 삽입
- 반복

### ⏱ 시간복잡도
- 평균 / 최악: O(N²)
- 최선: O(N) (이미 정렬된 경우)

### 💡 특징
- 안정 정렬
- 거의 정렬된 데이터에서 매우 효율적

---

## 4️⃣ Heap Sort (힙 정렬)

### 📖 개념
힙 자료구조를 이용해 최댓값(또는 최솟값)을 반복적으로 꺼내 정렬하는 방식.

### ⚙️ 작동 방식
- 배열을 Heapify (힙 구조로 변환)
- 루트(최댓값)와 마지막 요소 교환
- 힙 크기 감소 후 재정렬 반복

### ⏱ 시간복잡도
- 평균 / 최악 / 최선: O(N log N)

### 💡 특징
- 불안정 정렬
- 추가 메모리 거의 사용하지 않음

---

## 5️⃣ Quick Sort (퀵 정렬)

### 📖 개념
분할정복(Divide and Conquer) 기반 정렬.

### ⚙️ 작동 방식
1. Pivot 선택
2. Pivot보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 분할
3. Pivot 위치 확정
4. 왼쪽 / 오른쪽 부분을 재귀적으로 반복

### ⏱ 시간복잡도
- 평균: O(N log N)
- 최악: O(N²)
- Pivot이 균형 있게 나뉠수록 빠름

### 💡 특징
- 일반적으로 매우 빠름
- 구현 방식에 따라 성능 차이 발생
