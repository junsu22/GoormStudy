
# 📚 알고리즘 개념 정리 노트

---

## 🔹 다익스트라 (Dijkstra)

> 최단 경로 알고리즘  
> 탐욕적(Greedy) 방법 사용

### 특징
- 음의 가중치 ❌ (사용 불가)
- 최소 힙(Min Heap) 사용
- 우선순위 큐 기반 구현
- 가장 짧은 거리부터 선택

### 동작 과정
1. 시작 정점 거리 = 0
2. 가장 짧은 거리의 정점 선택
3. 이웃 정점 거리 갱신
4. 힙이 빌 때까지 반복

---

## 🔹 벨만-포드 (Bellman-Ford)

> 음의 가중치가 있는 경우 사용 가능한 최단 경로 알고리즘

### 특징
- 음의 가중치 허용
- 모든 간선을 반복적으로 검사
- 음수 사이클 탐지 가능

---

## 🔹 다이나믹 프로그래밍 (DP)

> 큰 문제를 작은 문제로 나누어 해결하고  
> 결과를 저장하여 재사용하는 설계 기법

### 핵심 개념
- 중복 계산 제거
- 실행 시간 단축
- 최적화 가능

### 접근 방식

#### 🔸 Top-Down (메모이제이션)
- 재귀 사용
- 계산 결과 저장
- 함수 호출 오버헤드 존재

#### 🔸 Bottom-Up (타블레이션)
- 반복문 사용
- 테이블 기반 구현
- 메모리 최적화 용이

### 예시

#### ✔ 피보나치 수열
- 중복 계산이 많음
- DP 적용 시 효율 향상

#### ✔ 배낭 문제
- 큰 문제 → 작은 부분 문제로 분할
- 최적 선택을 저장

### 장점
- 실행 시간 단축
- 구조 명확
- 중복 계산 감소

### 단점
- 추가 메모리 필요
- 설계가 복잡
- 모든 문제에 적용 가능한 것은 아님

---

## 🔹 유니온-파인드 (Union-Find)

> 집합 연산을 효율적으로 처리하는 자료구조

### 구성
- **Union** : 두 집합을 합침
- **Find** : 대표 원소 찾기

### 사용 예
- 최소 신장 트리(MST)
- 집합 연결 여부 판단

---

## 🔹 재귀 (Recursion)

> 자기 자신을 호출하는 함수

### 특징
- 콜 스택 사용
- 기저 조건(Base Case) 필요
- 최대 재귀 깊이 제한 존재

### 예시

#### ✔ 팩토리얼
5! = 5 × 4!

#### ✔ 피보나치
F(n) = F(n-1) + F(n-2)

#### ✔ 하노이 탑
- n-1 이동
- 가장 큰 원판 이동
- 다시 n-1 이동
