# 합리적 소비 (Rational Shopping)

##  문제 요약
N개의 상품 중에서 **가장 비싼 상품**과 **가장 싼 상품**을 찾는 문제

##  입력
```
5
watch 2000
scarf 1500
boots 4000
coat 10000
perfume 7000
```

- 첫 줄: 상품 개수 N
- 다음 N줄: 상품명 가격 (공백으로 구분)

##  출력
```
coat 10000
scarf 1500
```

- 첫 줄: 최고가 상품명과 가격
- 둘째 줄: 최저가 상품명과 가격

##  문제 조건
- 1 ≤ N ≤ 1,000 (상품 개수)
- 1 ≤ 가격 ≤ 100,000
- 상품명은 영어 소문자, 최대 10글자
- S는 상품명, P는 가격을 의미

##  해결 방법
1. 첫 번째 상품을 최대/최소로 초기화
2. 나머지 상품들을 순회하며:
   - 현재 가격 > 최고가 → 최고가 갱신
   - 현재 가격 < 최저가 → 최저가 갱신
3. 결과 출력

##  시간복잡도
- O(N) - 한 번의 반복문으로 해결
