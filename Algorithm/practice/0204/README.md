- 루트로 사용되는 하나의 노드가 있음.

ex. 
      |  node1   -child1 - node3

이항 분포의 누적 분포함수를 이용하여 앙상블 학습의 성능이 향상되는 이유를 설명.

p: 예측기 하나의 성능
n: 예측기 개수
반환값 : 다수결을 따를 때 성공할 확률, 다수결의견이 정확할 확률. 이항 분포의 누적분호 함수를 활용한다.

```python
from scipy.stats import binom
def ensemble_win_proba(n, p):
'''
p: 예측기 하나의 성능
n: 예측기 개수
반환값 : 다수결을 따를 때 성공할 확률
'''
return 1 - binom.cdf(int(n*0.4999), n, p)
```

적중률 51% 모델 1,000개의 다수결을 따르면 74.7% 정도의 적중률이 나온다.
```python
ensemble_win_proba(1000, 0.51)
# 0.7467...
```
적중률 51% 모델 10000개의 다수결을 따르면 97.8% 정도의 적중률이 나온다.

```python

# 0.9777...
```
적중률 80% 모델 10개의 다수결을 따르면 100% 에 가까운 성능이 가능하다.

배깅과 페이스팅
- 여러개의 동일 모델을 하나의 훈련셋의 다양한 부분집합을 대상으로 학습시키는 방식
- 부분집합을 임의로 선택할 때 중복허용 여부에 따라 앙상블 학습 방식이 달라진다.
배깅 : 중복 허용 샘플링 
페이스팅 : 중복 미허용 샘플링



- 분류 모델 : 직접 투표 방식. 
- 회귀 모델 : 예측값들의 평균


배깅/페이스팅 방식으로 훈련된 모델의 편향과 분산
- 개별 예측기의 경우에 비하면 편향은 조금 커지거나 비슷해지지만, 분산은 줄어든다.
이유: 배깅이 표본 샘플링의 다양성을 보다 많이 추가하기 때문.
배깅이 과대적합 의 위험성을 보다 줄여 준다. 그렇기 때문에 배깅 방식이 기본적으로
사용된다.

- 개별 예측기 : 배깅/ 페이스팅 방식으로 학습하면 전체 훈련셋을 대상으로 학습한 경우에 비해 편향이 커진다. 과소적합 위험성이 커진다.

BaggingClassfier 를 이용한 oob평가

평가 점수는 oob_score_ 속성에 저장된다.

```python
BaggingClassifier(
```

랜덤 패치와 랜덤 서브스페이스
- BaggingClassifier 는 특성에 대한 샘플링 기능도 지원한다.
(max_features, bootstrap_features)
- 이미지 등 매우 높은 차원(feature)의 데이터셋을 다룰때 유용하다.
- 더 다양한 예측기를 만들며, 편향이 커지지만 분산은 낮아진다.


max_features
- 학습에 사용할 특성 수 지정
- 특정 선택은 무작위
    정수인경우 : 지정된 수만큼 특성 선택
    부동소수점 : (∈[0,1])인경우 (포함) : 지정된 비율만큼 특성 선택

- max_samples와 유사 기능을 수행한다.

bootstrap_features 
- 학습에 사용할 특성을 선택할 때 중복허용 여부를 지정
- 기본값은 False다. (중복을 허용하지 않음)
- bootstrap 과 유사기능을 수행한다.



랜덤 서브 스페이스 기법
- 전체훈련세트대상. 훈련특성은 임의특성수 만큼 샘플링해 학습하는 기법

샘플에 대해 : bootstrap = False, max_sampe =1.0
특성에 대해 : bootstrap_features = True 또는 max_features 는 1.0 보다 작게

```python
BaggingClassifier(
    DecisionTreeClassifier(),
    n_estimators = 500,
    max_samples = 1.0,
    bootstrap = False,
    max_features = 0.5,
    bootstap_features = True,
    random_state = 42)
```


랜덤 포레스트
- 배깅/페이스팅 방법을 적용한 결정트리의 앙상블을 최적화 한 모델.
분류용도 ```RandomForestClassifier``` 
회귀용도 ```RandomForestRegressor```

```python
RandomForestClassifier(

BaggingClassifier(DecisionTreeClassfier(

```

랜덤포레스트 하이퍼파라미터
- BaggingClassfier 와 DecisionTreeClassifier 의 옵션을 거의 모두가짐.

-예외 
DecisionTreeClassifier 의 옵션중 :
splitter = 'random', presort  = False, max_samples = 1.0

BaggingClassfier의 옵션 중 :
base_estimator = DecisionTreeClassifier(...)


splitter = 'random' 옵션 : 
특성일부를 무작위적으로 선택한 후 최적의 임계값 선택
max_features = 'auto'가 RandomForestClassifier으 기본값.

따라서, 특성 선택에 무작위성 사용됨

선택되는 특성 수 : 약 sqrt(전체특성수)

결정트레이비해 편향은 크게, 분산은 낮게

>> 랜덤포레스트
전체 feature 중 무작위로 몇개 선택후 그중에 최적선택
>> 엑스트라 트리(익스트림 랜덤트리 앙상블): 
전체 feature 중 무작위로 몇개 선택 + 임곗값 무작위 선택 ,그중에 최적선택

- 일반적인 랜덤 포레스트 보다 속도가 훨씬빠르다.
(임계값 탐색없이 무작위로 뽑기때문에 빠르다.)
- 이 방식을 사용하면 편향이 늘고, 분산이 줄어든다. 


Feature Importance (각Feature가 예측에 얼마나 중요한지 수치화 한 것)
- 특성 중요도 : 
해당 특성을 사용한 마디가 평균적으로 불순도를 얼마나 감소시키는지 측정
(불순도를 많이 줄일수록 중요도가 커진다.)

- 사이킷런의 RandomForestClassifier
특성별 상대적 중요도를 측정해서 중요도의 전체 합이 1이 되도록한다.
feature_importances_ 속성에 저장이 된다.
