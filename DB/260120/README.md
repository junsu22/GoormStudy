이번 수업을 통해 관계형 데이터베이스와는 
다른 관점의 데이터 저장 방식이 존재한다는 것을 알게 되었고,
대규모 서비스에서 왜 NoSQL이 사용되는지 이해할 수 있었다.

## NoSQL이란?
- 대용량 데이터와 높은 트래픽을 처리하기 위해 등장
- 고정된 스키마가 없는 비관계형 데이터베이스

## NoSQL의 주요 특징
- 스키마 프리
- 수평 확장
- 분산 환경에 적합

## NoSQL의 종류
1. 문서형 DB (MongoDB)
2. 키-값 DB (DynamoDB)
3. 컬럼 패밀리 DB (Cassandra)
4. 그래프 DB (Neo4j)

## 장점
- 유연한 데이터 모델
- 높은 성능과 확장성

## 한계
- 표준화 부족
- 트랜잭션 일관성 약함

## 언제 쓰면 좋을까?
- 소셜 서비스, IoT, 게임, 대규모 트래픽 서비스
