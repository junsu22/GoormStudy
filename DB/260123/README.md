

## 1. 실습 개요

이번 실습에서는 QGIS의 기본 인터페이스를 익히고,  
공공데이터 플랫폼에서 제공하는 CSV 데이터를 활용하여  
공간 데이터(포인트 벡터)를 생성하는 과정을 진행하였다.

QGIS 설치 과정에서 시간이 다소 소요되어 강의 시간 내 설치를 완료하지 못했으나,  
강의 이후 개별적으로 설치를 마친 뒤 실습을 이어서 진행하였다.

---

## 2. QGIS 설치 및 기본 인터페이스 이해

- QGIS 3.40 LTR 버전 설치
- 레이어 패널, 속성 테이블, 지도 화면 구조 확인
- 배경지도(OSM) 및 기본 인터페이스 조작 경험

플러그인(TMS 계열) 설치를 통해 웹 지도 활용 가능 여부를 확인하였다.
OpenLayers Plugin은 버전 호환 이슈로 정상 동작하지 않아,
QuickMapServices 플러그인으로 대체하여 실습을 진행하였다.

---

## 3. 벡터 데이터 로드 및 레이어 관리
![](https://velog.velcdn.com/images/junsu22/post/137c83f2-9bc2-4b3b-99bf-26b557e1d383/image.png)

- 예제 SHP 벡터 데이터를 불러와 지도에 표시
- 레이어 추가 / 제거
- 레이어 ON/OFF를 통해 지도 가시성 조절

이를 통해 벡터 데이터와 레이어 관리의 기본 흐름을 이해하였다.

---

## 4. 공공데이터 CSV 활용 및 포인트 벡터 생성

공공데이터 플랫폼에서 제공하는  
**대전광역시 무료 와이파이 위치 CSV 데이터**를 활용하였다.

### 진행 과정
1. CSV 파일 인코딩 문제 확인 및 수정
2. CSV 파일을 QGIS에서 구분자로 분리된 텍스트 레이어로 불러오기
3. 위도(Y), 경도(X) 필드를 지정하여 포인트 데이터 생성
4. 좌표계는 EPSG:4326 (WGS84)로 설정

생성된 포인트 벡터 데이터를 지도 상에서 확인하였다.

---

## 5. 속성 테이블과 벡터 데이터 동시 확인

- CSV 기반 포인트 레이어의 속성 테이블을 열어  
  설치장소명, 주소, 위도, 경도 정보를 확인
- 포인트 벡터 데이터와 배경지도(OSM), 행정구역 레이어를  
  동시에 표시하여 공간 정보와 속성 정보를 함께 확인

이를 통해 속성 데이터와 공간 데이터의 관계를 이해하였다.

---

## 6. 데이터 정제 및 GeoPackage 저장
![](https://velog.velcdn.com/images/junsu22/post/f646ec80-d45f-4bfe-a0c4-65e4c2a7f5e6/image.png)

CSV 데이터 내 일부 좌표 오류로 인해  
정상적으로 생성된 포인트 외에  
지도 상에서 대륙을 가로질러 표시되는 비정상 포인트가 함께 확인되었다.

이에 위도 및 경도 값의 범위를 기준으로 필터링을 수행하여  
좌표 오류 데이터를 정제하였으며,  
정제된 포인트 벡터 데이터를 GeoPackage(.gpkg) 형식으로 저장하였다.

GeoPackage 형식을 활용함으로써  
여러 파일로 분리되는 SHP 형식 대비  
데이터 관리가 보다 효율적인 구조로 정리할 수 있었다.
![](https://velog.velcdn.com/images/junsu22/post/dfc1552a-a1c8-43ca-a082-b146fb4a6528/image.png)

## 7. 프로젝트 저장

작업 중인 레이어 구성과 지도 상태를 유지하기 위해  
QGIS 프로젝트 파일(`.qgz`)을 저장하였다.

---

## 8. 느낀 점

이번 실습을 통해 QGIS에서의 기본적인 데이터 흐름  
(속성 데이터 → 공간 데이터 → 벡터 레이어 → 저장 형식)을  
직접 경험할 수 있었다.

위도와 경도 정보가 포함된 CSV 데이터를 찾는 과정부터 쉽지 않았으며,
공공데이터 포털에 존재하는 다양한 데이터 중
실습에 적합한 형식을 선별하는 과정이 필요했다.

또한 CSV 인코딩 문제와 좌표 오류 등에서 어려움이 있었지만,
데이터를 하나씩 확인하고 수정하는 과정을 통해  
공간 데이터 처리의 중요성을 이해할 수 있었다.

이번 실습을 계기로 공간 데이터를 다루는 기술이
쉽지는 않지만 꼭 배우고 싶은 스킬이라는 생각이 들었고,
앞으로도 시간을 들여 차근차근 공부해보고 싶어졌다.
