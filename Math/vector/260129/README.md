## 정규분포 (normal distribution)
기호 X ~ N  
평균 μ 주변에 종 모양(가운데가 가장 큰)으로 몰려 있는 분포

X ~ N(μ, σ²)

평균 = μ    뮤.  
예: μ = 10  
→ "평균 뮤가 10이다"

분산 = σ²   시그마제곱 or 시그마스퀘어  
종 모양 (가운데가 제일 큼)  
σ² = 4  
→ "분산 시그마 제곱이 4다"

"엑스는 평균이 뮤 , 분산이 시그마 제곱인 정규 분포를 따른다."  
= "뮤 시그마 제곱 정규분포"  

뮤 시그마 => 평균이랑 분산 말하는거구나.

## 공분산 , 상관계수
방향성 체크

같이 커진다 . (양)  
반대로 움직인다. (음)  
상관없음 (0)

Cov(X,Y) = E[(X−μₓ)(Y−μᵧ)]

예시 :  
운동하는 시간이 많아지면 칼로리 소모가 커진다 (양)  
게임시간이 많아지면 잠을 잘 시간이 줄어든다 (음)  
1월생이라고 공부 잘하는건 아니다.(0)

## 상관계수 (예시)
공분산을 -1 ~ 1 사이 점수로 만든 것

ρ = Cov(X,Y) / (σₓ σᵧ)

날씨가 덥다 -> 아이스크림이 많이 팔린다. (+)  
게임을 많이했다. -> 잘 시간이 부족했다 (-)  
오늘 신은 양말색에 따라 시험점수가 달라지나 ?  
(0, 관계가 없다. 서로 다른 세상에 살고 있는 애들)

## PCA (주성분 분석)
정보는 최대한 살리면서 다이어트, 차원을 줄인다.

11개 컬럼을 5,6개로 압축 . (요약본)

(1) 센터링 :  
각 컬럼에서 평균을 빼준다.  
(0,0,0.. 중심점을 맞춘다.)  
데이터의 중심을 (0,0,0...)에 놓는 거

(2) 데이터가 가장 넓게 퍼진 방향을 찾는다.  
PC1  
(1번 주성분, 제일 중요한 축, 정보가 제일 많은 방향)

(3) 덜 중요한 축은 과감하게 버린다.  
(중요한거 빼고 다 버린다. PC2 , PC3..)

럭비공에 비유 : 그림자 만들기

데이터 : 럭비공  
빛을 어떤 방향에서 비추면 가장 길게 보일까?

제일 잘 보이는 방향 : 주성분  
가장 예쁜 그림자를 만들거야.(PCA)

고유 벡터 : 이쪽에서 보면 좋아요  
고유값 : 이 방향은 정보가 얼마나 많아요?

공분산 행렬 → 고유값 분해 → 큰 고유값부터 사용

PCA 많이 쓰이는 분야 :  
데이터시각화 / 속도 / 노이즈 제거

## 정규화 / 표준화

### 정규화 (0~1 줄세우는 작업)
사탕개수 :  
철수 1개 / 영희 3개 / 민수 5개

철수 → 0  
민수 → 1  
영희 → 0.5

사용하는 이유 :  
비율만 중요할때 , 그래프를 예쁘게 그리고 싶을때

### 표준화
사과들이 여러개 있음  
보통크기의 사과가 가장 많다.

우리는 이 평균 크기의 사과를 0이라고 하자.

"평균 크기의 사과를 0으로 만들고,  
표준편차 단위로 거리를 재는 거"

예시:  
표준편차 1개 떨어진 사과 → +1  
표준편차 2개 떨어진 사과 → +2

정리:  
평균보다 큰 사과 → +  
평균보다 작은 사과 → -  
평균 크기 사과 → 0
