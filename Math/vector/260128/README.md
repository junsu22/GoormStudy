SageMath 환경에서 직접 계산과 시뮬레이션을 수행한 실습 코드입니다.

## 🎮 주요 실습 예제

### 이항분포 & 포아송 분포 시뮬레이션

- 상황:  
  던전에서 몬스터 **1200마리**를 잡을 때  
  각 몬스터가 레어 아이템을 드롭할 확률이 **0.002**인 경우

- 목표:
  - 이항분포로 `P(X = 3)` 계산
  - 포아송 근사(`λ = np`)로 `P(X = 3)` 계산
  - 시뮬레이션 **50,000회**를 통해 `P(X = 3)` 추정 후 비교

- 환경:
  - SageMath (Web SageMathCell)
  - 난수 시드 고정으로 결과 재현 가능

---

## 🧠 포아송 분포 정리 (실습 기반)

포아송 분포란,  
시행 횟수가 많고 개별 사건의 발생 확률이 매우 작은 상황에서  
평균 발생 횟수를 기준으로  
사건의 발생 횟수를 근사적으로 나타내는 분포이다.

본 실습에서는  
몬스터 수가 많고 드롭 확률이 매우 작아  
이항분포를 포아송 분포로 근사할 수 있었다.

---

## ✨ 트러블슈팅

- 웹 SageMath 환경에서  
  대규모 이항 시뮬레이션(1200회 × 50,000번)이 매우 느리거나 실행되지 않는 문제 발생
- 해결:
  - 이항분포를 **포아송 분포로 근사**
  - 포아송 분포에서 직접 샘플링하여 시뮬레이션 수행

이를 통해 **포아송 근사의 실용적인 의미**를 체감할 수 있었다.
