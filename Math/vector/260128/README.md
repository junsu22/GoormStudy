# 260128 이해보다는 흐름을 익히는 수업

오늘 수업에서는  
앞으로 어떤 주제들을 배우게 되는지 전반적인 구조를 소개받는 시간이었다.

- 경우의 수(순열·조합)
- 확률의 기본 개념
- 확률변수와 분포
- 기댓값, 분산, 표준편차
- 베이즈 정리

한 번에 많은 내용이 등장해 정리가 쉽지 않았고,  
깊은 이해보다는 앞으로 배울 내용을 미리 보여주는 성격의 수업으로 느껴졌다.

많이 막막했지만 그래도 같은 수강생분들이 도와주셔서  
혼자 검색하며 막연하게 알고 있던 부분들이  
조금씩 정리되는 느낌을 받을 수 있었고,  
그 점이 정말 감사하게 느껴졌다.

수학 공부를 오래 쉬었던 입장에서  
수식을 보고 바로 이해했다고 말하기는 어렵지만,  
개념의 큰 흐름을 잡는 데에는 분명 도움이 되었다고 느낀다.

이후 학습을 위해  
학습했던 내용을 다시 정리해보는 방향으로  
공부를 이어가기로 결정했다.
