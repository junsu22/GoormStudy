# 벡터(Vector)와 정사영 (Projection) 정리
---

## 1. 벡터(Vector)

**벡터**는 **크기 + 방향**을 동시에 가지는 값이다.

- 예시: 속도, 힘, 위치 이동
- 좌표 형태로 표현 (2D, 3D, n차원)
- 벡터끼리 덧셈 가능

예시:
```
(1, 2) + (3, 4) = (4, 6)
```

---

## 2. 스칼라(Scalar)

**스칼라**는 **크기만** 가지는 값이다.

- 예시: 길이, 넓이, 질량, 온도
- 숫자 하나로 완전히 표현 가능

---

## 3. 벡터의 노름(Norm)

노름 = **벡터의 크기(길이)**  
→ “이 벡터가 얼마나 긴가?”

- 스칼라는 숫자 하나로 크기 표현 가능
- 벡터는 방향 + 크기 → 크기만 뽑아내는 연산이 필요
- 이 역할을 하는 것이 **노름(Norm)**

### 노름 계산식

```
||x|| = √(x₁² + x₂² + … + xₙ²)
```

---

## 4. 내적(Dot Product)

**두 벡터가 얼마나 같은 방향을 보고 있는지**를 나타내는 연산  
→ 결과는 **스칼라 값**

### 특징
- 같은 방향 → 값이 큼
- 서로 직교 → 0
- 반대 방향 → 음수

### 계산식

```
x · y = x₁y₁ + x₂y₂ + … + xₙyₙ
```

---

## 5. 코사인(cos)의 의미 

```
x · y = ||x|| · ||y|| · cosθ
```

### 한 줄 요약
**cosθ는 두 벡터가 “얼마나 같은 방향을 보고 있는지”를 알려주는 값**이다.

### 왜 cos를 쓰는가?
- 각도(θ)는 비교·계산이 불편함
- cos는 각도를 **-1 ~ 1 사이의 숫자**로 바꿔줌 (cos 값 범위: -1 ~ 1)
- **길이 영향은 제거하고 방향만 비교**할 수 있음

- cos 값 범위: -1 ~ 1
### cos 값 해석

| cosθ | 의미 | 직관 |
|---|---|---|
| 1 | 완전히 같은 방향 | 찰떡궁합 |
| 0 | 직각 | 무관 |
| -1 | 정반대 방향 | 극과 극 |

👉 내적은 **방향 유사도를 수치화**한 것

## 7. 정사영(Projection)

정사영(正射影)  
- 正(바를 정): 수직, 똑바로  
- 射(쏠 사): 비추다  
- 影(그림자 영): 그림자  

👉 **정사영 = 수직으로 떨어뜨린 그림자**

- 사영: 빛이 비스듬히
- 정사영: 빛이 수직으로

### 정사영 공식

```
proj = (x · a / a · a) * a
```

- 분자: x가 a 방향으로 얼마나 닮았는지
- 분모: a 자기 자신의 길이 제곱
- 결과: a 방향으로의 그림자 벡터

### 4차원 예제

![](https://velog.velcdn.com/images/junsu22/post/c068f05c-6b0a-46ad-99db-8798089acdb2/image.png)




```python
a = vector([1, 2, 3, 4])
x = vector([4, 3, 2, 1])

proj = (x.dot_product(a) / a.dot_product(a)) * a
```

#### 계산 과정

1. 내적  
```
4 + 6 + 6 + 4 = 20
```

2. a·a  
```
1 + 4 + 9 + 16 = 30
```

3. 비율  
```
20 / 30 = 2 / 3
```

4. 결과 벡터  
```
(2/3, 4/3, 2, 8/3)
```

# 느낀 점 (수포자 시점)

수업을 처음 들을 때는 벡터, 내적 같은 단어부터 부담이었다.
외국어 수업을 듣는 느낌이었고,
공식만 보면 무조건 어렵다고 생각했다.
이걸 이해해야 한다는 사실 자체가 막막했다.

교재를 다시 펼쳐 들고 개념을 하나씩 작게 뜯어보니,
벡터는 방향이 있는 값이고
노름은 길이라는 것을 알게 되었다.

정사영 같은 개념도 처음에는 굉장히 복잡해 보였다.
그런데 오늘 수업 중에
‘그림자’에 비유해 설명해 주셨던 것이 어렴풋이 기억났다.
혹시 영(影)이 정말 그림자라는 뜻일까 싶어 찾아보니
한자어였고,
‘바르게 쏘아 생긴 그림자’라는 의미라는 것도 알게 되었다.

물론 오늘 배운 내용을 완전히 이해했다고 말하기는 어렵다.
첫 시간이기도 하고 아직 낯설다.
그래도 막연했던 개념들이
조금은 형태를 갖추기 시작한 느낌은 든다.
